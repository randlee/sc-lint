A Synaptic Canvas component.

Home Announcements

sc-lint is a Rust lint tool for repository policy enforcement: crate boundary, portability and runtime analyzers, plus consumer-declared lint and test steps run from one sc-lint.toml.

Install: brew install randlee/tap/sc-lint, pip install sc-lint, cargo install sc-lint, or a platform archive from the releases page. After installing, sc-lint docs prints the offline user manual.

  • Repository: github.com/randlee/sc-lint
  • User manual: docs-bundle/README.md
  • Changes by release: CHANGELOG.md

Engineering documentation lives in the repository's docs/ directory.
