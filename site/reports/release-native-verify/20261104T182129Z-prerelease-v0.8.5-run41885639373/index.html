Overview

Each native target is verified by its own job on a GitHub-hosted runner for that target. The job downloads the archive and wheels for the tag, checks each against checksums.txt, runs the bundled binaries with --version, and installs each wheel under the target's Python to check its version. A prerelease run gates publication: release-preflight accepts it only while the prerelease commit is an ancestor of the release candidate and no artifact input changed between them.
